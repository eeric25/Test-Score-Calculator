# Test-Score-Calculator
**Authors:** Eric Espinoza and Manuel Nunez

**Course:** CIS-11 

**Date Published:** June 10, 2026

### Description: 
This LC-3 program calculates min, max, and average of 5 scores and assigns a letter grade.

### Step-by-Step Operation:
1. User is prompted to input 5 score values ranging from 0-100.
2. The program gets each score and compares it to the min max.
3. The average is calculated using relevant arithmetic operations.
4. The scores are assigned letter grades as follows: 

    **A:** 100 - 90 | **B:** 89 - 80 | **C:** 79 - 70 | **D:** 69 - 60 | **F:** 59 - 0

6. The final results are printed to the console.

### System Overview and Performance:

- Min, max, and average of 5 values are calculated in a single linear pass. 
- Arithmetic is performed using optimized loops of iterative addition.
- The program's consumption of memory is highly conserved.

### Future Improvements:
- Expanded Input Capacity: Allow for more than 5 test score inputs for calculation.
